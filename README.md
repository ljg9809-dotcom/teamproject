# 경상도in 부산

HTML, CSS, JavaScript로 만든 모바일 우선 웹 앱 시험본입니다.

## 실행

`dist/index.html`을 Chrome 또는 Edge로 열면 됩니다. 별도 패키지 설치나 빌드는 필요하지 않습니다. 사진과 글꼴을 불러오려면 인터넷 연결이 필요합니다.

## 파일

- `dist/index.html`: 페이지 기본 구조
- `dist/style.css`: 모바일·태블릿·PC 반응형 스타일
- `dist/app.js`: 예시 데이터, 화면 이동, 음식 필터, 상세 화면, 리뷰·게시글 작성, 사진 첨부, 공감, 저장 기능

## 시험 범위

지역·계절별 음식 소개, 음식별·가게별 미식평, 경상도 식문화, 메뉴 추천 게시판, 식문화 토론 게시판, 오늘의 음식 게시판을 제공합니다.

식당과 기존 평점·게시글은 시연용 예시입니다. 음식 사진은 실제 해당 음식과 다를 수 있는 연출 이미지입니다. 상세 화면에서 네이버 지도 검색으로 연결할 수 있습니다.

사용자가 작성한 글·리뷰·사진과 즐겨찾기는 localStorage를 통해 같은 브라우저에만 저장됩니다. 파일로 열 때의 저장 동작은 브라우저 설정에 따라 달라질 수 있습니다. 로그인, 서버 DB, 다른 사용자와의 공유, 실시간 위치·지도 연동은 아직 구현하지 않았습니다.

## 확인

- JavaScript 문법 검사 통과
- 로컬 HTTP 응답 200 확인
- 390px 모바일 화면에서 지역 필터, 음식 저장, 상세 화면, 게시글 등록 및 새로고침 후 유지 확인

외부 호스팅은 완료되지 않았습니다.
